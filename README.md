## Repository structure

| Folder | Contents |
|---|---|
| docs/ | Analysis notes, stakeholder analysis, LESP notes, meeting minutes, project management evidence |
| i-star/ | i* Strategic Dependency and Strategic Rationale models |
| bpmn-strategic/ | Strategic-level BPMN model of the enterprise |
| bpmn-operational/ | Operational BPMN models for the two agreed functionalities |
| camunda/ | Executable Camunda BPMN, Forms and run instructions |
| services/ | Service-task code and mock or sandbox external services |
| traceability/ | Traceability from stakeholder goals to BPMN to Camunda |
